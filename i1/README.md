# Digital Marketing Project 01: Competitor Analysis & Keyword Research

A responsive, single-page SEO research dashboard for the sample EdTech brand **LearnPro Academy**, focused on the India market. Built with HTML, CSS, vanilla JavaScript, Bootstrap 5 and Chart.js.

## What's included

- Project overview and research snapshot
- Searchable, filterable and sortable keyword table
- CSV export of the complete keyword dataset
- Competitor summaries for Coursera, upGrad and Simplilearn
- Search intent classification and topic clusters
- On-page SEO recommendations
- Interactive Chart.js visualizations
- Google Trends and Ubersuggest links with a verification workflow
- Conclusion, next steps and references

## Important data note

Keyword search volumes and SEO difficulty values are **illustrative estimates for demonstration and planning practice**. They are not verified live measurements and do not come from a live API. Verify values in a suitable current research tool before making business decisions. Competitor notes are a high-level educational summary and may become outdated.

## Open and run in VS Code

1. Open this project folder in Visual Studio Code.
2. In Extensions, search for **Live Server** (commonly published as *Live Server* by Ritwick Dey) and install it.
3. In Explorer, right-click `index.html` and select **Open with Live Server**. Alternatively, open `index.html` and click **Go Live** in the VS Code status bar.
4. Your browser opens the dashboard. Save edits to refresh the page.

No backend, build step, package installation or paid API is required. Bootstrap 5, Chart.js and web fonts load from CDNs, so an internet connection is required for those assets and the charts. The main page and table logic remain local.

## Interactions

- Search keywords or recommendations using the table search field.
- Filter the table by search intent or priority.
- Click keyword, monthly volume, SEO difficulty or priority headers to sort.
- Select **Export CSV** to download the illustrative keyword dataset.
- Use the left navigation to jump between project sections; on small screens, use the menu button.
- Charts visualize the same sample dataset and are not a live data connection.

## Files
